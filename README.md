# Kursach_1 — Анализ банковских транзакций
Приложение для анализа транзакций из Excel-файла.

## Описание
Проект реализует несколько функциональных модулей:
- **Главная страница** — приветствие, информация по картам, топ-5 транзакций, курсы валют и акций
- **Поиск по телефонным номерам** — поиск транзакций с мобильными номерами в описании
- **Траты по категории** — анализ трат по категории за последние 3 месяца

## Установка
poetry install


Создайте файл `.env` на основе `.env.example`:

API_KEY=ваш_ключ_apilayer
ALPHA_VANTAGE_KEY=ваш_ключ_alphavantage


## Структура проекта
src/
    utils.py — чтение Excel-файла
    views.py — главная страница (JSON-ответ)
    services.py — поиск по телефонным номерам
    reports.py — траты по категории
    main.py — точка входа
data/
    operations.xlsx
tests/
    ...
user_settings.json — настройки валют и акций
